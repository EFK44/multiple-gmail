multiple-gmail

All your Gmail accounts, in your AI apps.

What it is

multiple-gmail is a free, open-source desktop app for Windows, macOS and Linux. It lets AI apps that support MCP (Model Context Protocol), such as Claude, Gemini CLI, Cursor and VS Code, search, read, draft and label mail in several Gmail accounts at once. Each person runs their own copy with their own Google Cloud project. There is no hosted service.

Safety model

  • It runs locally on your computer. The local server only listens on 127.0.0.1.
  • Tokens and credentials are stored encrypted on your disk. The key is protected by Windows DPAPI, the macOS Keychain, or the Linux Secret Service keyring (a file only your user can read when no keyring is available).
  • There are no delete tools: the AI cannot delete or trash mail, drafts or labels.
  • Sending is allowed only after you approve the exact message.
  • It requests a single Google permission, gmail.modify, and never the permission to delete mail permanently.

Get it

Download the file for your system from GitHub Releases, or build it from source, and follow the step-by-step setup in the README. The source code is released under the MIT license.
